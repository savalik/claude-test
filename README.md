# wb-laptop-aggregator

Агрегатор объявлений о ноутбуках. MVP — коннектор Wildberries для четырёх
продавцов с фильтром по цене и характеристикам.

**Статус: этап 0 (разведка API).** Нормализация готова и покрыта тестами,
коннектора ещё нет — сначала нужно прогнать probe и заполнить конфиг.

## Что ищем

| Параметр | Значение |
|---|---|
| Продавцы | ХОЛОДИЛЬНИК.РУ, ОНЛАЙНТРЕЙД.РУ, СИТИЛИНК, М.ВИДЕО |
| Цена | до 50 000 ₽ |
| RAM | от 16 ГБ |
| Накопитель | SSD от 1 ТБ |

## Структура

```
wb_aggregator/
    config.py       ограничения, параметры API, TODO для заполнения из probe
    normalize.py    разбор цены и характеристик; чистые функции, без сети
    probe.py        разведка внутреннего API WB
tests/
    test_normalize.py   прогон нормализации на фикстуре
docs/
    01-service-spec.md      спецификация сервиса целиком
    02-wb-connector-spec.md спецификация коннектора WB
    03-mvp-plan.md          план MVP, этапы и критерии приёмки
```

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Требуется Python 3.10+ (используется синтаксис `X | Y` в аннотациях).

## Запуск

### Тесты нормализации

Сети не требуют, работают где угодно:

```bash
python -m tests.test_normalize
```

### Разведка API

```bash
python -m wb_aggregator.probe
```

Запускать с машины, у которой есть доступ к `wb.ru`. Скрипт ничего не сохраняет,
только печатает вердикты. Между запросами стоит пауза в 1.2 секунды — не убирать.

Если с текущего IP `wb.ru` быстро отвечает 429 (например, общий IP облачной
среды) — есть реверс-прокси relay: разворачивается на отдельном VPS с
российским IP, запросы идут через него. См. [relay/README.md](relay/README.md).
Настройка — две переменные окружения (`WB_RELAY_URL`, `WB_RELAY_TOKEN`), в
коде менять ничего не нужно.

Probe отвечает на пять вопросов:

1. Какой хост поиска живой и в какой обёртке приходит ответ.
2. `supplierId` для четырёх продавцов.
3. Имя рабочего параметра фильтра по продавцу и по цене; не протекают ли
   посторонние результаты.
4. Реальный потолок глубины пагинации и максимальный размер страницы.
5. Отдаёт ли `card.wb.ru` структурированные характеристики.

По результатам заполняются TODO в `wb_aggregator/config.py`. **До этого писать
коннектор рано** — имена параметров и id фасетов угадывать нельзя.

## Что уже работает

`normalize.py` разбирает оба формата цены (v18 `sizes[].price` и старый
`priceU`/`salePriceU`), извлекает RAM и объём накопителя из названия и
структурированных характеристик, применяет ограничения.

Текущий прогон на фикстуре из 10 кейсов:

```
 id      цена    RAM      SSD  вердикт
  1    47890₽     16     1024  PASS
  3    48300₽     16      512  skip    накопитель 512 ГБ < 1000 ГБ
  5    98990₽     32     1024  skip    цена 98990₽ > 50000₽
  6    39900₽     16     1024  skip    чужой продавец supplierId=999
  8    46000₽      —        —  REVIEW  не извлеклось: RAM, SSD
 10    44900₽     16     1024  PASS    (мусорная цена 390₽ отброшена)
```

Позиции с неизвлечёнными характеристиками уходят в `needs_review`, а не
отбрасываются молча.

## Оговорка

Используется внутренний недокументированный API Wildberries. Он не имеет гарантий
стабильности, и его использование не покрыто пользовательским соглашением
площадки. Для коммерческой работы у Wildberries есть официальный Public API
(dev.wildberries.ru).

Прежде чем сервис станет публичным, нужно проверить, покрывает ли официальный API
нужный сценарий. Подробности — в [docs/02-wb-connector-spec.md](docs/02-wb-connector-spec.md),
п. 10.

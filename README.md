# ЭлектроТест — PWA

## Установка

1. Скопируйте ваш файл `results.json` в папку рядом с `index.html`
2. Откройте `index.html` через веб-сервер (не через file://)

## Запуск локально

```bash
# Python 3
python3 -m http.server 8080

# Node.js
npx serve .
```

Затем откройте http://localhost:8080

## Формат results.json

```json
[
  {
    "id": 338580,
    "question": "Текст вопроса",
    "answers": [
      { "index": 0, "text": "Вариант А" },
      { "index": 1, "text": "Вариант Б" }
    ],
    "correct_answer": { "index": 0, "text": "Вариант А" }
  }
]
```

## Режимы тренировки

- **Случайные вопросы** — все вопросы в случайном порядке, без повторений
- **Билеты** — 10 вопросов за сессию  
- **Не выученные** — только вопросы без 3 правильных ответов подряд

## PWA

Приложение работает офлайн после первой загрузки.
На мобильных устройствах можно установить на экран Home через «Добавить на экран».
